# API Postman Collection

This repository contains a Postman collection for testing and documenting REST APIs.

## Features
- Authentication APIs
- CRUD operations
- Automated test scripts
- Environment support
- Response validation

## Files Included
- Postman Collection JSON
- Environment files
- API test cases

## Tools Used
- Postman
- REST API
- JavaScript (Postman Tests)

## Getting Started

1. Clone the repository
2. Import the collection into Postman
3. Import the environment file
4. Run requests or collection tests
